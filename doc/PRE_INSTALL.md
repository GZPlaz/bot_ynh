Before installing, create a bot at https://discord.com/developers/applications and copy its **token**.
On the **Bot** tab, enable **Server Members Intent** and **Message Content Intent**, or the bot can't log in.
You'll also need your own Discord user ID (Developer Mode → right-click yourself → Copy User ID).

This repository is private: give the server a read-only deploy key first and install from `git@github.com:GZPlaz/bot_ynh.git` (INSTALL.md, section 4.0).
