1. Quick start

  1. Check the Dashboard says ONLINE. If not, see Troubleshooting.
  2. Make sure the bot's role is at the top of Server Settings → Roles (just under yours). Almost every "Discord said no" error comes from this.
  3. Set the mod log channel in Automod and the event log channel in Logging.
  4. Add your trusted mods to the whitelist in Security so anti-nuke never punishes them.
  5. Add your first victim in Troll Control. 😈

3. Personality & chat features

  • Sass: ping the bot or reply to it and it answers with a random sarcastic line (3 s cooldown per person). "good bot" and "bad bot" get their own replies.
  • Custom commands: {{ prefix }}name → your response. {{ prefix }}help lists them.
  • Auto-responders: reply when a message contains or exactly matches a trigger, with an optional % chance.
  • Welcome message in the channel of your choice.

Placeholders usable in responses and lines:

{user}display name of the author
{mention}@mention of the author
{server}server name
{args}text after a custom command
{target}first @mention in the message (or the author); the victim in troll lines
{op}a random R6 operator

@everyone, @here and role pings are always blocked in bot output.

5. Automod & heat

Automod skips owners, the server owner, whitelisted users and roles, exempt roles, and anyone with Manage Messages.

Filters

Banned words (whole-word), Discord invites, mass mentions, non-allowlisted links, ALL CAPS. Hitting a filter deletes the message and adds a warning. Every N warnings (setting "Warnings before auto-timeout") triggers an automatic timeout.

🔥 Heat anti-spam

Each message adds heat: a base amount, plus extra per mention, link, attachment, emoji and line break, and a big bonus for repeating yourself. Heat cools down continuously. When someone crosses the heat limit, the bot deletes their last 20 seconds of messages and applies the chosen punishment. Repeat offenders get longer timeouts (base × strike count).

Tuning: with the defaults (10 per message, 12/s cooldown, limit 100), about 10 messages in quick succession triggers it, and normal chat never does. Raise the limit if it's too twitchy.

6. Security

🛡️ Anti-nuke

Watches the audit log. If an untrusted member or bot does too many of these within the window, they're punished (quarantine, strip roles, kick or ban) and owners get a DM:

channel delete / create · role delete / create · ban · kick · webhook create

With Auto-revert on, the bot then re-creates deleted channels and roles, deletes spam channels and roles, and unbans mass-banned users. Re-created roles come back empty, so you'll need to reassign members.

Always on (when enabled): bots added by untrusted members are kicked, and dangerous permissions (Administrator, Ban, Kick, Manage Server/Roles/Channels/Webhooks, Mention Everyone) granted by untrusted users are reverted.

Trusted = bot owners, the server owner, and the whitelist (Security page or /whitelist add). Anti-nuke can only punish people whose highest role is below the bot's.

🚨 Anti-raid

If X people join within Y seconds, raid mode switches on for the configured time. Everyone joining during raid mode gets the raid action, and optionally the whole server locks down. You can also force it with /raidmode or the dashboard. Separately, you can act on accounts younger than N days or with no avatar. Kicked or banned joiners get a DM explaining why.

✅ Verification

  1. Create a "Verified" role. In each channel (or category), deny View Channel to @everyone and allow it for Verified. Leave one #verify channel visible to everyone.
  2. In Security, enable verification and pick the role.
  3. In #verify, run /verifypanel. New members click the button and answer a quick math captcha to get the role.

☣️ Quarantine

Strips all roles (remembered), adds a "Quarantined" role that can't see any channel, and kicks them out of voice. /unquarantine or the Cases page restores their roles. The role is created automatically the first time you use it, and new channels hide from it automatically.

🔒 Lockdown

/lock and /unlock work on one channel; /lockdown on|off covers every text channel. The previous permissions are remembered and restored exactly.

7. Logging

Pick an event log channel and toggle categories: message edits and deletes, joins and leaves (with account age and a ⚠️ for new accounts), bans and unbans, nicknames, timeouts, role changes, voice joins/leaves/moves, and channel create/delete.

👻 Ghost-ping detector: if someone deletes a message that pinged a person within 60 seconds, the bot calls them out in the channel.

Messages the bot deletes itself (automod, purge, your secret commands) and everything the troll engine does are kept out of the logs automatically.

8. Cases

Every warn, timeout, kick, ban, temp-ban, softban, quarantine, anti-nuke punishment and note gets a numbered case. In Discord: /modlogs @user, /case 42, /note. In the panel, the Cases page lets you filter by action or user, remove cases, release quarantines and see temp-bans.

9. 🤫 Troll engine

How it works

  • Add a target in Troll Control, pick which trolls apply, and set their chance (%).
  • Message trolls roll chance × chaos on every message the target sends.
  • The timed loop (every N minutes) rolls the same odds and picks one active troll. Voice trolls only fire if they're in voice; the harsher ones are rarer.
  • Any troll can be fired manually with Fire 🚀 on the Troll Control page, or with a secret command.
  • Chaos (0–5) scales everything. 0 means only manual trolls.
  • The 🚨 Panic button (dashboard, or ,,panic) turns trolling off and undoes everything reversible: nicknames, shame roles, target timeouts and potato channels.
  • Bot owners are immune to everything and always win /stats, /clutch and /roast.

10. 🤫 Secret chat commands

Who can use them: bot owners (General → Owner IDs), plus, by default, every server admin (members with the Administrator permission) and an optional extra role. Change this in Troll Arsenal. Type them in any channel: the message is deleted instantly and never appears in the server's event log.

  • Bot owners are immune: if an admin aims a secret command at an owner, it's blocked and they get a "nice try" DM.
  • Every use by a non-owner is recorded in the panel's Logs → troll, so you can see who trolled whom.
  • ,,clone by an admin only works on clones whose owner allowed "anyone".

12. 🧬 Voice clones (opt-in only)

  1. A member runs /voiceclone optin, reads the explanation and chooses who may use their voice: bot owners only, or everyone.
  2. They upload 10–30 s of their own voice with /voiceclone sample. A Discord voice message works; clear speech, no game audio.
  3. Lazy friends: upload the clip for them on the Soundboard page instead. The bot DMs them the clip with Allow (owners only), Allow (everyone) and Delete buttons, and the clone activates the moment they tap Allow. If their DMs are closed, they run /voiceclone status to get the same buttons. Unapproved samples are deleted after 7 days.
  4. Use it with /mimic, ,,clone @user text, or the voice picker on the Soundboard.
  5. /voiceclone optout deletes the sample instantly. You can also delete clones from the Soundboard page.
A clone only ever activates after the person themselves agrees in Discord, whether they uploaded the clip or you did. The clone service adds an inaudible AI watermark, and /mimic labels its output in chat as AI.

Cloning needs the separate clone service (clone_server/ in the repo, roughly 4 GB RAM; a GPU makes it fast). Set its URL and token in Robot Voice & Clones, then press Test clone service on the Soundboard. Setup steps are in INSTALL.md.

13. 🏅 Leaderboard

Every player can be rated Tier 1 (best) to Tier 5 (worst). Tier names are editable in Leaderboard settings.

  • /leaderboard shows the tier list. /tier show shows one player, and /tier history shows their past changes with reasons.
  • Suggesting a change: anyone runs /tier suggest @player <tier> <reason>. A reason of 10–300 characters is required. Nothing changes until a reviewer approves.
  • Reviewing: suggestions appear in the review channel with ✅ Approve / ❌ Reject buttons (reject asks for an optional note), and on the Leaderboard page. The requester gets a DM with the verdict. Reviewers are bot owners, anyone with Manage Server, and the optional reviewer role. Nobody can review their own suggestion.
  • Direct edits: reviewers can use /tier set (tier 0 removes someone), or the "Set directly" form in the panel. These are logged in the history too.
  • Limits: one pending suggestion per person per player, and a configurable maximum of open suggestions per person.
  • Public page (optional): turn on "Public leaderboard page" to get a read-only tier list at {{ base }}/public/leaderboard that friends can open without logging in. It shows only names, avatars and tiers. You can also restrict it in YunoHost → Users → Permissions → siegebot.leaderboard.

14. 🧩 Plugins

The voice clone service is an optional plugin. You can install it when installing the app (the YunoHost installer asks), or later at any time: YunoHost web admin → Applications → SiegeBot → Configuration → Plugins, then toggle and save. Turning it off uninstalls it and frees the disk space. The Plugins page shows its status and has a connection test. A clone URL set in Robot Voice & Clones (e.g. a GPU PC) overrides the plugin.

16. Permissions checklist

  • Developer portal → Bot: Server Members Intent ✅ and Message Content Intent ✅.
  • Invite permissions: Administrator. That's the easy route; anti-nuke, quarantine, lockdown, voice jail and potato mode all need management permissions.
  • Role position: the bot's role must be above everyone it should moderate, rename, mute or quarantine.
  • Server owner: Discord never lets bots act on the server owner. That's a Discord rule, not a bug.

17. Troubleshooting

Dashboard: "LoginFailure / Improper token"Reset the token in the developer portal and paste it into General.
"PrivilegedIntentsRequired"Enable both intents (section 14), then click Restart.
Slash commands don't show upThey sync when the bot starts. Restart it, then reload Discord (Ctrl+R). Check the bot was invited with the applications.commands scope.
"Discord said no" / nickname or mute doesn't workRole position (section 14), or the target is the server owner.
Bot joins voice but there's no soundCheck the Logs page for "playback failed". On the server: sudo apt install ffmpeg libopus0, then upgrade the app.
Robot voice says nothingsudo apt install espeak-ng.
Clone: "service unreachable"Is the clone service running? Is the URL reachable from the YunoHost box (firewall/port)? Does the token match?
Clone is very slowNormal on CPU (10–40 s per sentence). Run the clone service on a machine with a GPU (--device cuda).
Anti-nuke punished a real modWhitelist them (or their role) in Security, then release them from Cases → Quarantined.
