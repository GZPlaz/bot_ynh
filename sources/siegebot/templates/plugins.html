🧩 Plugins

Optional add-ons. They need system-level installation, so they're switched on and off from YunoHost, not from here (the bot runs as a locked-down user that can't install software, on purpose).

🧬 Voice clone service

Powers opt-in AI voice clones (/voiceclone, /mimic). Needs about 4 GB RAM and 6 GB disk on CPU.

Status: {% if clone_url %}configured {{ clone_url }} (via {{ clone_source }}) {% else %}not installed{% endif %}

Install or remove it on this server

Web admin: Applications → SiegeBot → Configuration → Plugins → toggle Voice clone service → Save. Installing takes 10+ minutes. Turning it off uninstalls it and frees the disk space; opted-in voice samples are kept.

Command line:

sudo yunohost app config set {{ app_id }} main.plugins.clone_service -v 1   # install
sudo yunohost app config set {{ app_id }} main.plugins.clone_service -v 0   # remove

Or use a faster machine

Run the service on a gaming PC with a GPU (INSTALL.md, section 6b), then set its URL and token under Robot Voice & Clones. A URL set there overrides the YunoHost plugin.
